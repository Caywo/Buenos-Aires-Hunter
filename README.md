Buenos Aires Hunter es un videojuego del género Boomer Shooter, inspirado en títulos como DOOM y Ultrakill, ambientado en un contexto urbano de Buenos Aires. El proyecto propone una experiencia de combate rápida y frenética, en la que los jugadores deberán enfrentarse a distintos enemigos, utilizar recursos y cumplir los objetivos establecidos en cada partida.
El modo principal del juego será Extracción, complementado por los modos Supervivencia y Duelo. De esta manera, el proyecto busca adaptar las características principales del género a una propuesta propia, incorporando diferentes formas de juego dentro de un alcance adecuado para el desarrollo del proyecto.
